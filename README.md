# KJ Perfumes — Sistema de gestión

Repositorio base del proyecto. Stack definido:

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Prisma** (ORM) + **PostgreSQL**

Todavía sin modelo de datos, sin schema ni módulos — se suman más adelante.

## Instalación

```bash
npm install
cp .env.example .env
npm run dev
```

Abrir http://localhost:3000
